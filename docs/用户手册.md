# 用户手册

## 1. 界面概览与组件介绍

### 主视图与地图交互
* 主窗口左侧为 ArcGIS 地图视图，默认加载 ArcGISImagery 底图，并启用了鼠标跟踪以支持光标坐标显示与交互覆盖层。应用同时创建了用于渲染图像、障碍物和临时编辑的三个图形覆盖层，并把自定义图像覆盖控件叠加在地图视图之上。【F:Test_map_widget.cpp†L68-L121】
* 图像覆盖控件支持载入图片、平移、缩放与旋转：图片在载入时自动缩放并居中显示，提供可拖动的旋转手柄；滚轮在按住 Shift 时旋转、默认情况下缩放；左键拖动图片移动位置；固定后图像透明度降低并禁止继续拖动。【F:OverlayImageWidget.cpp†L139-L347】【F:OverlayImageWidget.cpp†L364-L477】

### 侧边控制面板
* “Pointer Coordinates” 区域实时显示地图光标的经纬度，鼠标离开视图时恢复占位符文本。【F:Test_map_widget.ui†L53-L70】【F:Test_map_widget.cpp†L268-L304】
* “Go to Location” 区域提供经纬度输入框与跳转按钮，支持以逗号或空格分隔的纬度、经度格式。【F:Test_map_widget.ui†L73-L93】【F:Test_map_widget.cpp†L136-L168】
* “Edit Pattern” 区域包含：
  * “Load Image/Modify Position” 按钮用于载入或解锁图像；
  * “Close Image” 按钮移除当前图像；
  * “Set Position” 按钮在图像面积合规时将图像固定到地图；
  * “Placement info” 面板显示图像在地图上的尺寸与格网划分统计；
  * “Assign Seed” 按钮打开种子分配窗口（仅在图像已固定时可用）。按钮的启用状态与提示文字会根据当前状态自动更新。【F:Test_map_widget.ui†L95-L175】【F:Test_map_widget.cpp†L306-L549】
* “Obstacle” 区域提供“Add Obstacle/Finish”和“Cancel/Delete”按钮，用于录入或撤销障碍区域；下方还有“Exit Map” 按钮关闭程序。【F:Test_map_widget.ui†L178-L226】【F:Test_map_widget.cpp†L741-L812】
* 状态栏会在关键操作（如坐标校验、图像导入、障碍编辑）时给出提示信息，帮助用户确认步骤是否成功。【F:Test_map_widget.cpp†L141-L413】【F:Test_map_widget.cpp†L741-L812】

### 种子分配弹窗
* “Pinned Image Grid” 窗口包含滚动预览区、种子列表与操作按钮：左侧滚动区展示原图或效果图并可叠加网格，右侧提供“Show effect/Show original”“Hide/Show grid lines”“Add/Delete seed”“Apply changes”等按钮，底部放置“Commit changes”按钮。【F:GridPreviewWindow.cpp†L606-L667】
* 种子列表中的每个条目包括序号、种子颜色、目标颜色、权重与通道选择（通道 1-5 以及“empty”），并提供颜色预览与点击采样能力。【F:GridPreviewWindow.cpp†L420-L499】
* 窗口内置调色板与取色器覆盖层：启动取色后可在屏幕任意位置采样颜色，并通过“Show color palette”和“Exit color-selection mode”控制调色面板与退出取色。【F:GridPreviewWindow.cpp†L46-L118】【F:GridPreviewWindow.cpp†L647-L709】【F:GridPreviewWindow.cpp†L1200-L1335】
* 当载入已固定的图像时，窗口会依据设定的网格间距生成列行数、绘制网格线，并在应用或查看效果时自动维护原始与修改后图像数据。【F:GridPreviewWindow.cpp†L779-L852】

## 2. 功能操作指南

### 2.1 前往指定位置
1. 在“Go to Location” 输入框中填入纬度、经度，可使用逗号或空格分隔，例如 `34.05, -118.25`。【F:Test_map_widget.cpp†L136-L168】
2. 点击“Go to location” 按钮，程序会校验范围（纬度 ±90°、经度 ±180°），若格式有误会在状态栏提示纠错信息。【F:Test_map_widget.cpp†L136-L168】
3. 校验通过后，地图自动平移缩放到指定坐标，并在状态栏显示当前定位结果。【F:Test_map_widget.cpp†L136-L168】

### 2.2 导入图像、设置位置、分配种子并查看结果
1. 在“Edit Pattern” 区域点击“Load Image/Modify Position”。若当前图像已固定，按钮会先解除固定并提示如何拖拽、缩放与旋转；否则弹出文件选择器载入常见格式图片并居中显示。【F:Test_map_widget.cpp†L306-L341】
2. 使用鼠标左键拖动定位图像，滚轮缩放，按住 Shift+滚轮旋转；也可以拖动图片上方的圆形旋转手柄精确旋转。【F:OverlayImageWidget.cpp†L139-L347】
3. 当图像尺寸符合要求时，点击“Set Position” 将图像与地图绑定。程序会转换当前视窗对应的四边形并锁定图像，随后图像会随地图移动缩放。【F:Test_map_widget.cpp†L542-L615】【F:Test_map_widget.cpp†L400-L414】【F:OverlayImageWidget.cpp†L397-L477】
4. 图像固定后点击“Assign Seed” 打开“Pinned Image Grid” 窗口。首次打开会根据地图尺寸计算网格单元大小，并生成原图与网格叠加预览。【F:Test_map_widget.cpp†L446-L493】【F:GridPreviewWindow.cpp†L779-L825】
5. 在右侧列表中使用“Add seed” 新增条目：
   * 选择通道（1-5 或 empty）。选择 empty 时无需设置种子颜色，表示该网格保留透明；
   * 填写目标颜色（RGB）与权重，必要时点击颜色预览启动取色器或显示调色板辅助选取。
   * 列表至少需要两个有效条目才能应用更改。【F:GridPreviewWindow.cpp†L420-L499】【F:GridPreviewWindow.cpp†L1208-L1283】
6. 点击“Apply changes” 根据目标颜色与权重执行种子分配。系统会遍历网格像素，依据与各目标颜色的加权距离找到最匹配的种子：
   * 匹配到 empty 通道时写入透明像素并将通道编号置为 0；
   * 匹配到具体通道时写入对应种子颜色并记录通道编号；
   * 障碍单元在此过程中被标记为 -1，并保持透明显示。
   生成的效果图可通过“Show effect/Show original”与“Hide/Show grid lines”切换预览。【F:GridPreviewWindow.cpp†L1508-L1544】【F:GridPreviewWindow.cpp†L1556-L1639】【F:GridPreviewWindow.cpp†L1645-L1673】
7. 满意后点击“Commit changes”，弹窗会把更新后的图像与通道网格返回主窗口，主视图立即刷新固定图像并在状态栏提示成功。【F:GridPreviewWindow.cpp†L1675-L1680】【F:Test_map_widget.cpp†L495-L511】

### 2.3 添加障碍物
1. 点击侧边栏的“Add Obstacle” 开始绘制，按钮文字会变为“Finish”，状态栏提示使用鼠标右键拾取顶点。【F:Test_map_widget.cpp†L741-L758】
2. 在地图上右键依次选择至少三个点构成多边形。过程中会以红色圆点与半透明填充预览当前轮廓。【F:Test_map_widget.cpp†L239-L264】【F:Test_map_widget.cpp†L815-L851】
3. 拾取完成后再次点击“Finish” 保存障碍；障碍多边形会以半透明红色填充显示并记录到全局列表。【F:Test_map_widget.cpp†L760-L783】
4. 若要撤销正在绘制的障碍，点击“Cancel”；若未在绘制状态下点击“Delete” 则会删除最近保存的障碍及其图形。【F:Test_map_widget.cpp†L785-L812】

### 2.4 查看种子分配、障碍与空通道的具体逻辑
* 种子条目的通道列表固定为 5 个可用通道加一个 “empty” 选项，empty 表示通道编号 0 并使用透明像素。【F:GridPreviewWindow.cpp†L46-L59】【F:GridPreviewWindow.cpp†L455-L459】【F:GridPreviewWindow.cpp†L374-L421】
* 应用更改时系统要求至少两个有效种子（必须填写目标颜色与正权重，若非 empty 还需提供种子颜色）。种子定义会被收集成数组供后续匹配。【F:GridPreviewWindow.cpp†L1208-L1283】
* 对每个网格单元：
  * 若单元被障碍覆盖，则通道编号写为 -1，图像像素保持透明；
  * 否则计算该单元原始颜色与各目标颜色的平方距离并除以对应权重，选择最小值；
  * empty 通道保持透明并记录为 0；其它通道写入种子颜色并记录通道编号。【F:GridPreviewWindow.cpp†L1508-L1639】
* 障碍掩膜来源于主图像固定时保存的地图四边形与障碍多边形映射，映射后落在障碍内的网格单元会同步写入掩膜数组，在最终通道网格和效果图生成时统一设置为 -1 与透明。【F:GridPreviewWindow.cpp†L1048-L1168】
* 生成的通道网格通过全局变量传回主窗口，后续可用于其他处理；网格间距以常量 0.3 米为单位根据图像物理尺寸推算列行数。【F:GridState.h†L1-L9】【F:GridPreviewWindow.cpp†L779-L825】

## 3. 附注
* 若需要重新编辑固定图像，可再次点击“Modify Position” 解锁后调整并重新固定；提交过种子效果后若想载入新图像，需要先关闭当前图像以避免误覆盖。【F:Test_map_widget.cpp†L306-L549】
* 所有操作均会在状态栏给出即时反馈，建议在执行关键步骤后确认提示信息，以确保流程正确无误。【F:Test_map_widget.cpp†L141-L413】【F:Test_map_widget.cpp†L741-L812】
